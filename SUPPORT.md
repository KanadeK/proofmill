# Support

Before opening an issue:

1. run `proofmill --version`;
2. run `proofmill explain RULE_CODE`;
3. follow [docs/REPAIR_GUIDE.md](docs/REPAIR_GUIDE.md);
4. rerun against the exact PDF intended for upload.

For a suspected false positive, attach the redacted JSON report and a synthetic PDF that
reproduces the geometry. Never upload an unpublished manuscript to a public issue.

Questions about KDP accounts, publishing decisions, copyright, or a platform review should
go to the platform's support team. ProofMill can explain structural evidence but cannot
override a platform decision.
