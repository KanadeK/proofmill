# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-07-30

### Added

- Local KDP paperback interior and cover PDF preflight.
- Exact trim, bleed, page-count, cover-wrap, and paper-specific spine math.
- Font embedding, safe text, effective image DPI, annotation, transparency, form,
  JavaScript, attachment, thin-line, rotation, spread, and blank-page checks.
- Deterministic privacy-preserving JSON and self-contained HTML reports.
- Paired project configuration with JSON Schema and page-count derivation.
- Passing and intentionally failing PDF examples.
- Cross-platform CI, coverage, packaging, release, security, and Pages workflows.
- English and Simplified Chinese documentation plus rule and repair references.
